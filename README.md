# Ordinal Journey

Ordinal Journey is an interactive educational website where you progress through different learning paths using an ordinal-based progression system.  
Choose your Journey — Math, Reading, Writing, or Science — and increase your ordinal value as you explore each subject.

This project blends incremental game mechanics with learning concepts to create a fun, safe, and school-friendly experience.

---

## Features

- Multiple subject-based learning journeys  
- Ordinal progression system  
- Clean, simple interface  
- Settings menu for switching subjects  
- Educational theme designed to be school-friendly  
- Built with lightweight, accessible web technologies  

More features will be added as development continues.

---

## How to Play

Ordinal Journey is designed to be simple at first and expand over time.  
Here’s how to get started:

### 1. Choose Your Journey
Open the **Settings** tab and select which subject you want to play:
- Math Journey  
- Reading Journey  
- Writing Journey  
- Science Journey  

Each journey represents a different learning path.

### 2. Increase Your Ordinal
Press the main button to increase your ordinal value.  
Your ordinal represents your progress through the current journey.

### 3. Unlock New Layers (Coming Soon)
As your ordinal grows, you will unlock:
- Subject-specific prestige layers  
- New upgrades  
- Achievements  
- Additional learning paths  

These systems will expand as the game develops.

### 4. Switch Subjects Anytime
You can freely switch between journeys in the Settings tab.  
Each subject will eventually have its own progression and upgrades.

### 5. Explore and Experiment
Ordinal Journey is meant to be a calm, exploratory learning experience.  
Try different subjects, see how the UI changes, and watch your ordinal grow.
